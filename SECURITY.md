# Security policy

## Reporting

Please report suspected vulnerabilities privately to the repository maintainer through GitHub's private vulnerability reporting feature, if enabled. Avoid publishing personal data, phone numbers, message content, or session files in issues.

## Sensitive data

- Do not commit SQLite databases, logs, browser profiles, QR codes, session tokens, or credentials.
- Treat message text and phone numbers as personal data.
- Keep dependencies updated and review changes before deployment.
- This project is not an official WhatsApp integration and does not guarantee message delivery or account safety.
